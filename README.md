# 台风实况信息展示网站

面向**沿海居民**的台风实况信息网站，提供实时、易读的台风动态与分级预警，帮助普通用户快速了解"台风叫什么、在哪、往哪走、风多大、要不要防范"。

## 项目目标

- 让非专业的沿海居民一眼看懂台风关键信息和风险等级
- 权威数据源 + 实时更新 + 移动端优先
- 中国四级预警（蓝/黄/橙/红）清晰呈现与防御指引

## 当前内容

- `docs/计划书.md` —— 项目计划书（需求、功能、预警分级、架构、里程碑、风险）
- `src/` —— 前端/后端代码（待开发）
- `public/` / `assets/` —— 静态资源（待补充）

## 核心信息字段

1. 台风名称 / 编号
2. 当前位置（经纬度、距参照地距离）
3. 移动路径与方向（已发生轨迹 + 预报路径）
4. 风力强度（最大风力、风速、气压、风圈半径）
5. 分级预警（蓝 / 黄 / 橙 / 红）
