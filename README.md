# 台风实况信息展示网站

面向**沿海居民**的台风实况信息网站（原型）：实时、易读、带分级预警，帮助普通人快速了解"台风叫什么、在哪、往哪走、风多大、要不要防范"。

## 核心信息字段

1. 台风名称 / 编号
2. 当前位置（经纬度、距参照城市的方位与距离）
3. 移动路径与方向（历史实线 + 预报虚线 + 移速）
4. 风力强度（最大风力、风速、气压、风圈半径）
5. 分级预警（蓝 / 黄 / 橙 / 红）

## 技术栈（当前原型）

- 纯静态 HTML + CSS + 原生 JS（零构建、易部署）
- 地图：Leaflet（CDN，在线加载）；加载失败时自动降级为离线 SVG 示意地图
- 数据源：当前为**示例数据**，已预留 `loadTyphoon()` 接口位，可接入中央气象台 nmc.cn

## 目录结构

```
typhoon/
├── index.html            # 页面结构（移动端优先）
├── assets/
│   ├── css/style.css     # 样式与四级预警配色
│   └── js/
│       ├── data.js       # 示例数据 + 四级预警定义 + 接口位
│       ├── map.js        # Leaflet 地图 / SVG 降级
│       └── app.js        # UI 渲染与预警联动
├── docs/计划书.md         # 项目计划书
└── README.md
```

## 本地运行

直接双击 `index.html` 即可；或起本地服务：

```bash
python3 -m http.server 8099
# 浏览器打开 http://127.0.0.1:8099
```

## 说明

本网站展示的气象数据均以来源官方发布为准，仅为便民信息聚合与可视化，不作为应急决策唯一依据。当前页面数据为模拟值。
